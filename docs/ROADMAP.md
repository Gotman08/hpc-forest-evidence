# Research roadmap

_Future work is listed as planned, not as evidence._

## Available in this release

- External comparison protocol in English and French
- Complete fixed-trace controller timing records
- Explicit largest-case CPU subset, including near-flat curves
- Offline integrity/arithmetic verification and rejection tests
- Figures, provenance and blank comparison templates

## Planned evaluations

The 19 October instruction uses the completed Sol MAX primes run as a single technical pilot, then moves to fifteen subjects × four models (Sol, Luna, Astra and Terra), all at MAX. A full primes campaign for every model is no longer a prerequisite. Subject qualification, deployment, fresh capacity checks, unchanged budgets and audited reception remain required before new model calls. See the [dated campaign scope](RECEIVED-2026-10-19.md). The planned sixty cells are not sixty received results.

| Question | Status | Evidence needed before a claim |
| --- | --- | --- |
| Does the controller change improve programs produced by real models? | Not demonstrated | Fresh matched searches, qualified transport/evaluator, identical budgets and audited final confirmations |
| How stable are gains across independent searches? | Not established | Preregistered seeds and subjects, complete coverage and dispersion between searches |
| Does weight learning help beyond a frozen model? | Not demonstrated | Qualified training/inference, frozen episodes, disjoint data, reload checks and all learning costs |
| Can another implementation be compared fairly? | Protocol available | Benchmark qualification and new observations under matched external conditions |

## How future evidence enters

Retain previous releases and their raw records. Admit a new cohort only after verifying source identity, environment, correctness, timing completeness, provenance and budgets. Preserve incidents, rejections, missing results and no-gain outcomes. Review the documentation and figures against recalculated values before updating any claim.

This repository does not promise completion of every planned experiment. An incomplete study must state which cells were not executed and why.
